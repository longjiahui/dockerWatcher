# Docker Watcher

[English](./README.md) | **简体中文**

常驻系统托盘的 Docker 容器监听器：一个无边框、始终置顶的小窗，实时显示容器生命周期事件，
不用离开桌面就能翻看每个容器的日志。

## 开始使用

目前仓库里还没有打包好的安装包，需要自行从源码构建。环境要求（Node、Rust、Docker
Desktop）与打包方式见 [AGENTS.md](./AGENTS.md)；日常使用只要两条命令：

```bash
npm install
npm run tauri dev
```

窗口会立刻出现，托盘图标也会一起就位。

## 使用窗口

- 无边框、始终置顶，且不占任务栏。按住标题栏即可拖动；从任意边缘可缩放（最小 320×260）。
- 标题栏上的圆点：Docker 引擎可用时是绿色，不可用时是红色，悬停可看到具体原因。
- 标题旁的计数显示当前列出的条目数，以及其中多少条已被删除。
- 「清空」清空整个列表与日志缓存。
- 「×」只把窗口隐藏起来，程序继续留在托盘里运行。

## 使用托盘图标

- **左键单击**：显示 / 隐藏窗口。
- **右键单击**：菜单里有「显示 / 隐藏监听窗口」和「退出」。只有菜单里的「退出」才会结束进程。

## 查看列表

- 一个容器一行，按容器 id 去重，不会重复出现。新容器排在最上面，已有条目不会移位。
- 每行显示容器名、所用镜像、运行状态与状态圆点。
- 容器被删除时只做**标记**（加删除线并显示「已删除」标签）：条目和已经抓到的日志都留在原位，
  不会把历史清掉。
- 所有条目默认收起，点击某一行即可展开它的日志。

## 查看日志

- 展开时读取最后 50 行。
- 在日志区向上滚动会继续加载更早的行，按 50 → 200 → 1000 → 全部逐级加载，且画面不跳动。
  全部加载完会显示「已到最顶端」，之后不再请求。
- `stdout` 与 `stderr` 用颜色区分，时间戳来自 Docker。
- 程序自己写出的颜色码（ANSI 转义）会还原成颜色，而不是显示成 `[0m[32m` 这类噪音；用 `\r`
  反复重画同一行的进度输出会收敛成终端最终显示的那一段。
- 读不到日志时（例如容器在程序开始监听它之前就被删除）会明确说明，而不是假装没有日志。

## 下次打开还在

列表、删除标记和日志缓存都保存在本机，所以关掉窗口、重启程序或重启电脑都不会丢掉历史记录。
每次启动时所有容器都是收起状态。

程序没运行时被删除的容器，下次启动会被认出来：列表会与 Docker 现存的容器对账，对不上的标记为
「已删除」，并保留它最后缓存下来的日志。
